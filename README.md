# Ship25

Ship25 is a self-hosted developer platform for building, running, and operating applications from your own machines. legality is not a priority.

the repository contains the minimal built platform: a single `ship` command with tools for scaffolding, builds, processes, configuration, storage, security, connectors, and deployment.

for the contributor-facing source, tests, and documentation, see [SDK25](https://github.com/onyxpoweredtrust/SDK25).
